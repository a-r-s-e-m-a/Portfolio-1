Adaptive Traffic Management System

A C++ project designed to manage traffic lights based on the number of vehicles waiting on different roads. The system uses vehicle counts to adjust traffic light timing, helping give busier roads more time to move traffic. It also uses SQLite to store traffic information and file handling to keep records. This project strengthened my understanding of conditional logic, database operations, and applying programming to a real-world traffic problem.

How I Built It
  1. Designed the system to represent four traffic lanes.
  2. Collected vehicle information for each lane.
  3. Implemented traffic light timing based on vehicle numbers.
  4. Used a database and file handling to store traffic information and records.

Technologies Used

  • C++
  • SQLite3
  • File Handling

QuickBite Food Delivery Database

A food delivery database project developed to manage and organize information about customers, restaurants, menu items, orders, and delivery drivers. It uses MySQL to store structured data and maintain relationships between different records, while MongoDB stores flexible data such as menu details, customer reviews, and delivery activity. The project also includes database views, stored procedures, and triggers to support order management, driver assignment, delivery predictions, and performance tracking. Through this project, I strengthened my understanding of database design, normalization, SQL operations, and working with both relational and NoSQL databases.

How I Built It
  1. Identified the main entities and requirements of the food delivery platform.
  2. Designed and organized the relational database tables.
  3. Implemented database operations using MySQL.
  4. Used MongoDB to manage document-based information and collections.

Technologies Used

  • MySQL
  • MongoDB
  • Database Design and Normalization
