Projects

Simple Calculator

A simple calculator application developed to perform basic mathematical operations, including addition, subtraction, multiplication, division, power, logarithm and also others. The project allows users to enter numbers and select an operation to calculate the result. It helped me practice programming fundamentals, user input, conditional statements, and basic problem-solving.

Library Management System

A console-based application designed to help manage library activities and book records. It supports organizing book information and handling common operations such as borrowing and returning books. This project helped me understand how to organize data, work with records, and apply programming concepts to solve a practical problem in library management.

Inventory Management System

An application developed to manage product information and keep track of available stock. It helps users organize inventory records, monitor product quantities, and manage basic stock-related operations. Through this project, I practiced working with data, organizing product records, and developing a solution for everyday inventory management tasks.

Adaptive Traffic Management System

A C++ project designed to manage traffic lights based on the number of vehicles waiting on different roads. The system uses vehicle counts to adjust traffic light timing, helping give busier roads more time to move traffic. It also uses SQLite to store traffic information and file handling to keep records. This project strengthened my understanding of conditional logic, database operations, and applying programming to a real-world traffic problem.
